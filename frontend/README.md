# EventEase - Full-Stack Event Management System

EventEase is a complete web application for managing events, from creation to ticketing, built with the MERN stack.

## Project Structure

-   `/backend`: Node.js, Express, MongoDB server.
-   `/`: React.js (Vite) frontend.

## Setup Instructions

### 1. Backend Setup

```bash
cd backend
npm install
# Create a .env file from .env.sample and fill in your details
npm run dev
